# UI统一了，怎么还是不满意？我用AI做游戏又返工了

AI配音；按真实开发记录整理的第一人称口播，未冒称用户逐字签收。

以前的界面，先能用再说。血量、能量、弹药，都往左上角塞。

现在改成这样。画风是统一了，但说实话，我还是不满意。

这期就聊聊，我用AI做游戏，怎么又在界面上返工了。

最开始也改过一版。先把菜单和信息放进去，但这一版，我还是觉得不好看。

后来这轮，先重新做标题页。背景、钟表标志，再到按钮，尽量往同一个方向靠。

背景和大钟是AI生成后，实际放进游戏的素材。不是只做一张好看的效果图。

左边这些按钮，也是真的能点。开始游戏、设定、新手教程，没把整页糊成一张图片。

字体也统一换成了像素字体。至少打开不同菜单，不至于像进了另一个游戏。

暗一点的蓝绿色面板，加上铜色边框和圆角按钮。暂停、设置，都沿用这一套。

暂停菜单再分出页签。背包放一页，装备没开放，就老老实实标没开放。

地图也接着用同一套字体和颜色。想先让这些界面，看着像同一个项目里长出来的。

到这一步，总算没那么散了。但统一字体、统一颜色，就等于好看了吗？

游戏里还有另一件事：跑跳和瞄准的时候，得看懂自己还剩什么。

第二轮这里还是一整块信息框。内容不少，但人物在下面跑，眼睛还得往角上找。

所以第三轮，把武器文字和那块底框拿掉。留下角色头像，旁边放爱心和具体血量。

下面这条细线是共鸣，不是血量。先把不同资源分开，也别每样都抢着当主角。

血量长起来，爱心会换行，数字仍然放在一行。这些小地方，做之前还真容易漏掉。

弹药也换成小子弹图标。不过要说明一下，这轮基础空中弹药改成了一发。

所以这里不只是换皮，规则也调整了。不能拿两版不同的录像，说成同条件下变好用了。

二段跳和钩索，则按实际解锁、可用状态显示。没拿到的能力，不提前画个图标装有。

还有人物旁边这个圈。空中瞄准进入慢时间，圈就显示剩下的时间能量。

这轮开枪本身不扣时间能量，空中瞄准的慢时间才消耗。落地以后，再慢慢恢复。

比起一直盯左上角，把这部分提示放到人物附近，是这轮在试的方向。

但圈会不会挡人物？图标够不够清楚？这些还是得放进连续操作里看，不能只看截图。

改了这么一轮，要问我满意了吗？还是没有。这版先留着，后面很可能还会改。

接下来，我想再比较一下：中文标题要不要更突出，按钮和大钟的比例，是不是还能再调。

还有按钮、图标和游戏画面放在一起，到底搭不搭。不能每个零件单看都行，拼起来就各玩各的。

下一轮也许先做减法，少加点装饰，把字号、间距和重点先理顺。别一不满意，就让AI再加一层。

这期用的是开发过程留下的实录和截图。现在这套还是候选效果，不是最终定稿。

我也是边做边学。大家觉得现在最该先改哪儿？标题、菜单，还是游戏里的提示？评论区给点建议。
