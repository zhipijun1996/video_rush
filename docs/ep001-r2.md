用户决定参考现成TileSet，视频表述为“有明确许可的TileSet”：四套为CC0，Underworld为作者许可，不能笼统宣称全部开源。希望有辨识度、规则清楚的像素语言更适合自己用AI持续制作，是当前选择与待验证假设。保留真实三次生成对照，不能推导成像素画简单、AI天然擅长或现已稳定量产。

## 生产与交付

```bash
python -m video_rush produce --spec episodes/ep001-r2.json --source /workspace/gunman-rush --local-only
```

新增presentation=montage及montage_weights，用30FPS整数帧分配短切；同一函数计算时间线与来源字幕。拒绝循环不足的实机源。当前快切只支持配音、BGM和原创音效，game_audio_gain必须为0，以免原声与切图错配。两项真实FFmpeg测试验证颜色帧切换、来源标签变化及短录像拒绝；原有测试继续保留。缓存键包含渲染模块SHA，修改辅助函数也能失效旧切片。

首次本地验收正确保留了两条freeze检测，但旧判断器按整段口播的assets推断动态/静态，把合法静态对照图与相邻影片第一帧混为意外定格。现在按真实montage切点分类，只容忍FFmpeg freeze_end的一帧边界误差；另外两项回归检查确认计划静帧可登记，延伸到真正录像的长定格仍被拒绝，未放宽五秒检测。初始失败report与日志保留在build/ep001-r2-initial-quality.json和build/ep001-r2-initial.log。后期三段9秒短原片改为不同窗口，与家园原片交替，减少相同动作重复播放。

完整口播见[文稿](ep001-r2-script.md)。执行结果在ep001-r2-verification.json实际运行后登记。最终交付含MP4、封面、投稿标题简介、字幕和来源，媒体不提交Git。按用户现有偏好走Actions下载；须托管端真实成功、下载核验后才标交付。自动技术检查不能替代手机完整试听和观感判断。
