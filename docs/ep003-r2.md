# ep003-r2：九武器、升级分支与真实关卡重制

修订用户反馈：上一版只围绕六条二级分支介绍，基础武器与升级关系不清楚，幽默不足，重复出生平台演示；回旋刃、散华后续改向、磁雷跳爆连飞与奇点的路线自由度展示不充分。

本版为三把基础武器（普通枪、影步手里剑、反冲炸弹）加六条二级分支，共九种。六个三级节点继承对应二级普攻并增加主动技能，不额外数成六套新武器。升级关系图是编辑性机制说明，不冒充游戏现有升级界面或正式授予链已完成。

再次通过 ls-remote 核实 main 仍为7be8c340372d1e20db6685cbd6a559191821eb0e。Godot4.7.2按项目配置固定。源仓库只读；使用既有隔离归档中的正式DemoApp和同一风铃平原Seed。新驱动 route_weapons.gd 只用一次 return_to_segment 初始化真实关卡检查点、一次 equip 指定装备，关闭可选瞄准慢时，其余移动、瞄准、跳跃、攻击都走原Router/Motor，原怪物AI、碰撞和资源不改。镜头中标注开发关卡测试，不能冒充自然解锁、完整从出生走来或整图通关。

## 机制和验证

- 普通枪、基础炸弹、三连、激光和奇点：真实登上关卡中x1040..1280、角色落脚y约-140的高台；未改平台或给角色传送到结果。
- 散华：两次实际 weapon_blinked 分别向右和向左。第二段重采样方向。
- 回旋刃：先反向闪至右上，空中控制刀到角色下方，手动召回后真实caught，入射方向改为左上，实际Motor向左上运行。纠正上一版“直线召回”被讲成整体缺乏变向的印象；高速召回路径仍锁定当刻直线，变向通过控刃位置和接刃入射方向达成。
- 磁吸雷：先地面投放黏附，跳近后手动遥爆升空，之后两次空中普攻直接爆炸。要求至少三个真实blast事件，第一包grounded、后两包airborne。当前地面矿雷是手动遥爆，不是自动定时炸弹；源代码不支持的自动定时行为没有被编造。
- 奇点：原地停住时可重新选方向，随后沿新方向出发。左右镜头使用不同检查点，明确不是同一障碍的受控对照。“最想玩灵活”是开发者口吻的方向偏好，不证明平衡或体验最强。
- 实际遇敌：使用既有关卡敌人，记录committed_damage及energy_recovered；没有假靶子、加资源、关闭AI或中途位置注入。

正式高台对照只有普通枪/三连使用同版同Seed同检查点与匹配操作；其它不同窗口不拼成连续通关。录制全程原运行时指纹前后相等，源仓库工作区不变。纯无头输入探针只叫轨迹验证，成品素材来自随后真实图形渲染，不能混称。
