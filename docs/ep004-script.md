# 打中了，却像没打中？我用AI给游戏补点打击感

第一人称为证据整理后的编辑叙述，AI配音；手机试听与用户验收待审核。

这只怪死了。不过这姿势……你就说死没死吧。

后来我想，至少得让它真的趴下。飞着的，也得把翅膀收起来。

我在用AI做一款靠反冲跳跃赶路的游戏，叫失序之钟。这次先不加新武器，补补动作和打击感。

我想弄清楚：同样的操作和伤害，光改画面、声音，能差多少？

先看人物。之前能跑能跳，但一些状态不太好读。这轮先补了待机和下落的动作。

下落时，围巾会往上飘。站着和往下掉，轮廓就不一样了。

起跳和落地，各补了一点尘土。看脚底，别光盯着枪。

这里没把人跳得更高。是同一套动作，把离地和踩实的瞬间交代清楚。

从高处落下来，会有更重的落地声、短震动和一点下蹲。

下蹲只是视觉收尾，一走就能打断。别在那儿罚站。

当然，也有翻车。新跑步图做了两版，都没留下。单看还行，连起来的步态和握枪衔接还是不对。

所以现在跑步还沿用旧图，只调整步伐跟实际位移的对应。没做好的，就先别硬上。

开枪也一样。枪响，只能说明开火了。命中怪、打到墙、打空，得分清楚。

这次把这些声音拆开，也给光束和回旋刃补了表现。声音很满，不代表这一枪真打中了。

怪物这边，先只做两个样板：地上冲过来的，和空中俯冲的。没有一口气铺到所有怪。

先给受击一个短亮色，让身体缩一下。

再加方向性的尖芒和细粒子，让命中的位置更清楚。

这里的特效只跟真实扣血走。子弹擦过去，或者伤害被拒绝，都不能先演一套挨打。

死亡就更明显了。早期直接把活图翻过去，就当死了。

中间还试过爆裂消失。但最后，还是选了倒地留尸。

这次补了真正的受伤和死亡姿态。地面的怪趴下，飞怪折翼，再落到地上。

左边爆完消失。右边倒下，尸体留下。

飞怪也一样，折翼，掉落，留在地上。

但帧多也不一定顺。你看这只旧外观的飞怪，受伤恢复时，身体轮廓还会突然变一下。

还有个很扫兴的问题：场景里尸体留住了，读档后却还可能丢。能录一段短片，离整套接好还差一步。

之前新加的死亡音被嫌怪，也撤回了。现在用回原来的声音，别拿新做了当成更好听。

这轮我学到的，是先让动作的开始、真正命中和结束，都有清楚的回应，再考虑加多少特效。

用AI做这些，我会先拿一只怪，把走动、挨打和倒地连着看，再去补下一只。

但到底顺不顺、爽不爽，最后还是得上手。这两个分支都还在打磨，没有合进主线。

你觉得现在更缺哪块：人物动作，还是怪物挨打的反应？欢迎直接挑毛病，我接着改。
