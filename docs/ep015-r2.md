# ep015-r2 / 公开 ep14：主动越顶与穿身的牧风者战斗

按用户反馈重录一、二阶段。前版把站墙角打通误当成了合适的展示方式：虽然通关和输入检查通过，但未体现玩家与 Boss 的持续对抗。这一版使用最新核对的 PR150 `c721b20aa9c34ea30b0498ee786f0a2c52f7d22d`（2026-11-12 10:24:44 UTC 更新，Draft、未合并），以实际追近、越顶、穿身、换边后的反击窗口组织完整战斗。保持无配音、游戏原声、原速和少量打法字幕，旧片与原始录屏保留。

## 操作如何改变

角色从场内的独立测试起点 `(600,742)` 出发；之后只提交普通 Router 输入，不改游戏 AI、数值、碰撞、阶段或角色位置。采用源仓库 `tests/world/windkeeper_crossing.gd` 验证过的两类输入方法，录制时没有调用其中的无敌、阶段、位置或强制招组夹具。

- Boss 在地面逼近：普通起跳，空中慢时瞄准0.5秒，再用一次斜向反冲越过头部，落地后反击。
- Boss 预备扑击：保持地面站位；实际起跳后迎向其来路，从抬起的身体下跑到身后，不把它变成空对空。
- 换边后：利用新版原朝向招组的收势窗口射击或原生蓄力回血，随后再读转身与追击。没有持续站在边角刷输出。
- 三阶段：保留走下旧台阶、0.5秒游戏内慢时、反冲到邻台的打法，不用空中连续射击。

新的 `windkeeper_interactive.gd` 复用源 `legal_input_pilot.gd` 的瞄点/遮挡查询。剧情、原始画面或 Boss 行为没有为了拍摄而被改写。源新版的朝向锁定、前向踏波和扑击空隙来自该固定提交，不能把它们归到旧版本。

## 实际本地结果

完成真实 MovieMaker / Xvfb / Mesa 录制并通关，成片125.367秒。基础5格生命、Boss满血510、原始伤害和物理保留；每次腾空最多一枪，实际27次空中射击全部使用原有 AirFocus 连续30个实时帧，即0.5秒。三阶段19次真实离台、反冲和邻台落地逐一关联。期间有真实受击和回血，不能称作无伤。

一阶段4次越顶、3次地面穿身；二阶段4次越顶、2次地面穿身。所有计入的越顶都在实际相对位置换边时处于 Boss 上方，且 Boss 当时未腾空；所有穿身都在 Boss 实际腾空时沿地面跑过，没有起跳或空中攻击。两阶段玩家横向活动范围分别约955、1084世界单位，Boss横向活动范围约432、417世界单位。

按场地两侧各110世界单位的边缘带统计，前版两阶段停留比例都是100%；新版分别约2.1%、12.6%，单次最长停留0.28秒、1.32秒。这是明确的录制行为指标，不代表已经替用户通过观感审核。

`boss_interaction.py` 对上述轨迹独立计数，不只相信分镜或动作名称。每个早期阶段须反复越顶、至少一次地面穿身，边缘停留不超过20%、连续停留不超过2秒，同时玩家与 Boss 都必须有足够活动范围。即使有少数换边事件，只要其余时间仍在墙角刷输出，整条也会被拒绝。相关反例有回归测试。

本地115项测试通过，1项可选浏览器测试跳过。[两次输入诊断](ep015-r2-probes.json)均为无头检查，不冒称其产生了画面；最终交付另有真实原生录制与不可变执行驱动收据。[本地成片核验](ep015-r2-local-check.json)逐项核对38份交付、18份固定Git Blob、原片及驱动；整片解码、字幕时间、黑屏/静帧、原声削波检查通过，10/55/110秒各4秒声音没有新增偏移。已抽查实际越顶、穿身、对应字幕和封面。
