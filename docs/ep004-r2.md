# ep004-r2：开头字幕、删段与结尾修订

按用户本轮反馈修订ep004，沿用已核实的两个分支和真实原片，不重新抓新历史或录游戏。

- 开头“这只怪死了。”单独合成配音，字幕覆盖这一条真实配音的完整时间窗；“不过这姿势……”另作短句，镜头从实际死亡附近开始，再切近景。原版Edge第一句元数据结束约1.556秒，第二句约1.508秒开始，约48毫秒重叠；现在全片句字幕在下一句开始处收束，并新增禁止字幕交叠的技术检查。字幕仍非逐字强制对齐，手机完整试听单列。
- 删除视频里整个读档问题段落和相关解释卡，投稿简介也删除这一话题。来源文档按原件保留，未把历史失败改写成通过。
- 结尾按用户意思改为：“现在这套还在打磨。说实话，打击感还是没达到我自己想象中的感觉。”随后以萌新身份问动作、特效或声音哪里最该先改，请观众在评论区给建议。此处是用户提供的主观感受，不冒称已收集观众反馈。

分镜 `episodes/ep004-r2.json`，素材表 `episodes/ep004-r2-assets.json`，连续文稿 [ep004-r2-script.md](ep004-r2-script.md)。原ep004和原下载记录保留。新版本独立目录 `build/episodes/ep004-r2/`，不覆盖旧成片。

继续带对应原游戏音效及用户指定轻BGM；仍是两个未合主线的开发候选。26段不变的真实配音及其哈希/边界回执复用，开头两段及结尾三段重新实际合成；全片重新编排与渲染。预计31段、约3分17秒，实际时长以成品报告为准。

新增两项针对实际问题的测试：原Edge交叠反例不再同时显示两句，短开场字幕严格绑定单条配音完整时间窗；本地28项测试通过。技术验收不代表人类听感或游戏手感验收。

原始来源、许可证及边界：见 [ep004制作说明](ep004.md) 与 `research/ep004-source-checks.json`。本修订仍不修改游戏工作区、整合分支或上传B站。实际远端执行、下载哈希及解码验证完成后另记验证文件。
