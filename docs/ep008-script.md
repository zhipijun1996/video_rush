# 《拍拍波》介绍片口播

终于下课了！数学题，先放一边。今天的操场最强，必须是我。

小伙伴，别跑。拍两下手，咱俩决一死战！

波动拳！然后，被对面原路退回。大招读条半天，伤害全算我头上。

这是拍拍波。我在做失序之钟时，借着AI，把小学对波做成了一个小游戏。

结果做着做着，小学操场的战斗力，开始失控。

规则从三招开始：充气攒能量，一气放小波，免费防御挡小波。

先拍两下，亮框再选招，窗口结束一起揭晓。手别急，先跟上拍子。

现在是单机打电脑。它在你选择前就暗选好了，你得猜它这回合想干什么。

攒气的时候怕挨揍，出手的时候怕被挡。想帅一下，还得先看看自己有没有气。

然后，我加了一点点特效。三气中波，红头带一绑：波——动——拳！

五气，大波。十字手一架，斯派修姆光线。不是，这还是小学操场吗？

两边同时开大？特写一人一半，排面谁也不能少。

对面都变成光了，我的防御还是平底锅。锅：挡小波可以，这个真不行。

一气，展开AT力场。中波挡得住，大波挡不住。别头铁。

两气，独角兽觉醒！对面五气大招，我两气挡完。排面，拉满。

防住哪有弹回去爽。一气，魔法筒。你的小波，归你了。

但魔法筒只能反弹小波。想把中波也送回去？两气，宇智波反弹。

对了，对面也会。喊得最大声的我，挨得最完整。

大波也不是随便乱放。两波相撞会削掉伤害，气少的时候，小波也能帮你少挨一点。

嫌攒气慢，还有快充。没被打中，一次加两气；被打中，这次一点不给。

更要命的是，不管充没充上，下回合都过热。蓄了个寂寞，还得冷静一回合。

所以最纠结的不是按哪个按钮。是他这五格气，到底会不会拿来打我？

我先开个反弹，他要是不放波，这两气就白交了。小小几根火柴，主打一个互相猜心思。

不想一上来就十个按钮？故事模式有八个同学，一路赢，一路学新招。

通关八关，才解锁十招进阶对战。别急着成神，先把课间基础打好。

还有连战。赢一场，双方满血、气归零，再来。看看你能当几场操场最强。

赢了先别急着结算。JOJO风格胜利姿势——下课之前，我是最强！

现在公开试玩已经能玩，接下来准备发到B站Toy。正式入口，会放在投稿简介里。

你们小时候还有什么离谱招式？评论区报一下。下一个操场大招，没准就是它。

坏了，上课了。拯救世界，下个课间再说。
