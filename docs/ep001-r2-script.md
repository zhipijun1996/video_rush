# ep01节奏修订 · 连续口播稿

第一人称按用户自述和历史证据重写，未冒称用户逐句签收。“四三九九”为配音读法，画面字幕使用4399。

我让AI帮我画游戏。你看这些图，是不是还挺像那么回事？

结果放进游戏……为啥我的游戏这么四三九九？

这是我用AI做的《失序之钟》。这期就聊聊，为什么图很好看，做出来却不是那么回事。

最初想要这种手绘平原：草坡、远山、机械遗迹。光看一张，很容易心动。

角色、风车、岩壁，也都能画得挺细。但这些漂亮图片，还不是能直接玩的关卡。

角色得动，平台得能拼，镜头还会往前走。单张图的构图，管不了后面十几屏。

最早用简化素材接进游戏，原图里的体积和层次，一下就丢了不少。

那怎么办？我当时想得很直接：不好看，就再画细一点。

加草，加石头，换背景。单独拿出来看，都像是进步了。

可一拼回关卡，还是这些重复的平台。细节多了，整体那股味儿没跟上。

后来还把各种拐角和接缝补齐。能拼起来了，不代表拼出来就自然。

再把地图填厚一点，又像一排墙。随机地图能生成，画面还是得一屏一屏看。

我才发现，AI设计单图很好看，但做成一整个游戏，真不是同一回事。

转角怎么接，人物怎么站，下一屏怎么延续，都得另外设计。多画几张，替代不了这些事。

后来试过反过来做：先画完整岸体，再按画里的站面做碰撞和路线。

局部确实更像一个地方。但当时只有两套布局，整张随机地图还没解决。

所以我决定换个思路，先参考现成、许可明确的TileSet，不再只靠散图往上堆。

这几套放进同一个实验场景比较。角色走起来，再看地形边缘、背景和落点。

有了参考，先把配色、轮廓和像素密度定下来，再让AI沿着这个方向画。

现在我更想靠近《动物井》那种感觉：不靠堆满细节，也能一眼认出自己的样子。

先收住颜色，让轮廓和光把气氛撑起来。这是我接下来更想试的方向。

规则清楚一点，我希望AI也更容易跟住。但能不能稳定做出来，还得继续验。

同样的提示词，角色兜帽都还会换颜色。光写一句像素风，显然还不够。

所以现在是先选母版，再让人物、地形、机关往同一个方向靠。做完还得放一起看。

这是后来接进游戏的画面。风格集中了一些，但我还不想说，美术问题已经解决。

地形的大轮廓、重复素材的痕迹，跨屏以后像不像同一个地方，都还得继续改。

现在我更关心的，是这套画法能不能反复用。先做好一个小地方，换个布局，再跑一次。

后面会继续分享开发进度。顺利的放，不顺利的也放，看看最后到底能做成什么样。

你觉得我该继续手绘，还是先沿着这种像素风做下去？评论区给我点建议。
