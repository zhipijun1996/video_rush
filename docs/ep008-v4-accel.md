# 拍拍波：加速互切、双重曝光和配乐收束

本轮根据用户对上一条21秒试剪的反馈继续，范围仍是独立短片段，不推广全片。用户说末尾BGM不合适，此处按最近交付的连续试剪末尾处理；未声称修改了旧全片。

动作各组对应镜头从12帧、9帧、6帧、4帧缩短到3帧，保持普通播放速度，通过缩短剪辑窗口加速节奏。最后不再来回切，进入12帧脸部双重曝光，接3帧推掌叠画，再进入原生游戏发射。动漫源时间单向推进，没有反复倒放起手。叠画是原创小学生RGBA图层覆盖在短动漫片段上，透明度最高55%，按检查过的眼线和嘴部坐标绘制；没有合成游戏结果。画面与时间表见输出double-exposure.png和shot-list.csv。观感依然需要人工审核。

原先配乐是整段战斗摇滚持续覆盖互怼，末尾仅220毫秒淡出。新版战斗音乐在实际命中后150毫秒内退出，让第一句普通童声反应有留白。最后一句完成后20毫秒起，使用相同E G A B E主题倒序的五个音做尼龙吉他收束；最后落主音，预留释放尾音，避免直接截断未完成乐句。music/score.m4a为实际混音增益后的无对白试听；score.mid为对应音符，cues.json记录音乐进出与台词结束点。原音源仍是MIT授权FluidR3 GM，原创编曲不冒称神经音乐生成或真人乐队录音。此处收尾为短试剪，合入全片时需要接下一次反转，而非在此结束整片。

配音不重做，日语喊招仍只出现一次。新童声AAC复用上次实际生成的Qwen表演，游戏画面、声音仍来自原连续对局第8回合；源bank逐项验签。第三方街霸声音与动漫短片许可状态沿用此前未确认状态，无新增公开投稿。

复现：`python -m tools.make_paipai_accel`，随后`python -m tools.paipai_accel_delivery`。全新Runner用GH_TOKEN读取V2已交付输入bank，VR_BRIDGE_ARTIFACTS恢复那句新增童声。离线保留审片包的portable/、extra/和sources.json以避免临时Artifact过期。输出为独立build/episodes/ep008-v4-accel/，旧版文件保持原哈希。

工程增加可替换的剪辑计划、片段渲染与混音函数，共用已经验证的逐镜头成片检查，不复制整套生产框架。V3默认入口保持其原有计划和配乐。
